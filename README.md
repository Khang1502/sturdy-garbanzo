# WebTest — Bài lab 1–8

Bản chỉnh sửa từ HGK.zip theo giáo trình thực hành Lập trình Windows 2025.

## Tải bài

- [Tải WebTest_Lab1-8.zip](https://github.com/Khang1502/sturdy-garbanzo/raw/refs/heads/main/Downloads/WebTest_Lab1-8.zip)
- Hoặc chọn **Code → Download ZIP** để tải cả kho.

Sau khi giải nén bản WebTest_Lab1-8.zip, đọc `WebTest/HUONG_DAN.md`,
chạy hai script trong `WebTest/Database`, rồi mở `WebTest/WebTest.sln`.
